📌 Problem Statement

Nalanda University maintains a large collection of ancient manuscripts, each identified by a unique Archive ID. Implement Binary Search to efficiently locate the first occurrence of a given Archive ID in the sorted collection.

⚙️ Algorithm — Binary Search

  1. Start with the sorted array of Archive IDs.
  2. Set low = 0 and high = n - 1.
  3. Find the middle element using mid = low + (high - low) / 2.
  4. If the middle element is equal to the target Archive ID, store its position and continue searching on the left side to find the first occurrence.
  5. If the middle element is smaller than the target, search in the right half.
  6. If the middle element is greater than the target, search in the left half.
  7. Continue until the first occurrence is found or the search range becomes empty.

💻 C Code

#include <stdio.h>

int firstOccurrence(int arr[], int n, int target)
{
    int low = 0;
    int high = n - 1;
    int result = -1;

    while (low <= high)
    {
        int mid = low + (high - low) / 2;

        if (arr[mid] == target)
        {
            result = mid;

            /* Continue searching on the left side */
            high = mid - 1;
        }
        else if (arr[mid] < target)
        {
            low = mid + 1;
        }
        else
        {
            high = mid - 1;
        }
    }

    return result;
}

int main()
{
    int archiveIDs[] = {
        101, 104, 108, 112, 112,
        112, 115, 119, 125, 130
    };

    int n = sizeof(archiveIDs) / sizeof(archiveIDs[0]);

    int target = 112;

    printf("Archive IDs:\n");

    for (int i = 0; i < n; i++)
    {
        printf("%d ", archiveIDs[i]);
    }

    int position = firstOccurrence(archiveIDs, n, target);

    printf("\n\nSearching for Archive ID: %d\n", target);

    if (position != -1)
    {
        printf("First occurrence found at index: %d\n", position);
        printf("Position: %d\n", position + 1);
    }
    else
    {
        printf("Archive ID not found.\n");
    }

    return 0;
}
