🎯 Problem Statement

You are designing a grid layout for a next-generation server farm in Hyderabad or a cellular network tower distribution system across a metropolitan area.

The grid is modeled as an N × N matrix. You must place N high-frequency antennas on this grid.

To avoid electromagnetic interference, no two antennas can share the same row, column, or diagonal line of sight. This problem is known as the N-Queens Problem.

📋 Algorithm

  1. Start with an empty N × N chessboard.
  2. Place one antenna in each row.
  3. Check whether the selected position is safe.
  4. A position is safe if no antenna exists in the same column.
  5. Check both diagonals for possible conflicts.
  6. If the position is safe, place the antenna.
  7. Move to the next row and repeat the process.
  8. If no safe position is available, backtrack to the previous row.
  9. Continue until all N antennas are placed.

📐 Safety Conditions

Same Column: column[row] != column[i]

Same Diagonal: abs(column[row] - column[i]) != abs(row - i)

💻 C Program

#include <stdio.h>
#include <stdlib.h>

#define N 4

int board[N][N];

// Check whether an antenna can be placed
int isSafe(int row, int col)
{
    // Check the same column
    for (int i = 0; i < row; i++)
    {
        if (board[i][col] == 1)
        {
            return 0;
        }
    }

    // Check upper-left diagonal
    for (int i = row - 1, j = col - 1;
         i >= 0 && j >= 0;
         i--, j--)
    {
        if (board[i][j] == 1)
        {
            return 0;
        }
    }

    // Check upper-right diagonal
    for (int i = row - 1, j = col + 1;
         i >= 0 && j < N;
         i--, j++)
    {
        if (board[i][j] == 1)
        {
            return 0;
        }
    }

    return 1;
}

// Solve N-Queens using backtracking
int solveNQueens(int row)
{
    // All rows are completed
    if (row == N)
    {
        return 1;
    }

    // Try every column in current row
    for (int col = 0; col < N; col++)
    {
        if (isSafe(row, col))
        {
            // Place antenna
            board[row][col] = 1;

            // Move to next row
            if (solveNQueens(row + 1))
            {
                return 1;
            }

            // Backtrack
            board[row][col] = 0;
        }
    }

    return 0;
}

// Display the board
void printBoard()
{
    printf("N-Queens Solution:\n\n");

    for (int i = 0; i < N; i++)
    {
        for (int j = 0; j < N; j++)
        {
            if (board[i][j] == 1)
            {
                printf("Q ");
            }
            else
            {
                printf(". ");
            }
        }

        printf("\n");
    }
}

int main()
{
    // Initialize board with zeros
    for (int i = 0; i < N; i++)
    {
        for (int j = 0; j < N; j++)
        {
            board[i][j] = 0;
        }
    }

    // Solve N-Queens problem
    if (solveNQueens(0))
    {
        printBoard();
    }
    else
    {
        printf("No solution exists.\n");
    }

    return 0;
}

🔍 Result

⏱️ Time and Space Complexity

Time Complexity: O(N!)

Space Complexity: O(N²)

✅ Conclusion

The N-Queens problem is solved using the Backtracking technique. The algorithm places antennas row by row and backtracks whenever a safe position is not available.
