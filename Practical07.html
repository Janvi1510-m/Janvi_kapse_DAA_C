🎯 Problem Statement

You are a bioinformatics scientist at the Indian Institute of Science (IISc), Bengaluru, working in a genetic research laboratory.

Scientists are comparing DNA samples from two species found in the Western Ghats to identify common evolutionary patterns.

Your task is to determine the length of the Longest Common Subsequence (LCS) between two DNA sequences. The LCS helps identify common genetic patterns between the sequences.

📋 Algorithm

  1. Take two DNA sequences as input.
  2. Create a Dynamic Programming table.
  3. Initialize the first row and first column with zero.
  4. Compare characters of both sequences.
  5. If the characters match, add 1 to the diagonal value.
  6. If the characters do not match, take the maximum of the upper and left values.
  7. Continue until the complete DP table is filled.
  8. The last cell of the table contains the LCS length.

🧬 Input DNA Sequences

DNA Sequence 1: AGGTAB

DNA Sequence 2: GXTXAYB

💻 C Program

#include <stdio.h>
#include <string.h>

// Find maximum of two numbers
int max(int a, int b)
{
    return (a > b) ? a : b;
}

// Find LCS length using Dynamic Programming
int LCS(char X[], char Y[])
{
    int m = strlen(X);
    int n = strlen(Y);

    int dp[m + 1][n + 1];

    // Initialize first row and first column
    for (int i = 0; i <= m; i++)
    {
        for (int j = 0; j <= n; j++)
        {
            if (i == 0 || j == 0)
            {
                dp[i][j] = 0;
            }
        }
    }

    // Fill the DP table
    for (int i = 1; i <= m; i++)
    {
        for (int j = 1; j <= n; j++)
        {
            // If characters are equal
            if (X[i - 1] == Y[j - 1])
            {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            }
            else
            {
                // Take maximum of upper and left value
                dp[i][j] = max(dp[i - 1][j],
                               dp[i][j - 1]);
            }
        }
    }

    return dp[m][n];
}

int main()
{
    char X[] = "AGGTAB";
    char Y[] = "GXTXAYB";

    // Calculate LCS length
    int result = LCS(X, Y);

    printf("DNA Sequence 1: %s\n", X);
    printf("DNA Sequence 2: %s\n", Y);

    printf("\nLength of Longest Common Subsequence = %d\n",
           result);

    return 0;
}

📊 Dynamic Programming Table

G 1 1 1 1 1 1 1
T 1 1 2 2 2 2 2
A 1 1 2 2 3 3 3
B 1 1 2 2 3 3 4

📤 Output

DNA Sequence 1: AGGTAB
DNA Sequence 2: GXTXAYB

Length of Longest Common Subsequence = 4

🔍 Result

The Longest Common Subsequence between the two DNA sequences has length 4.

One LCS is: GTAB

⏱️ Time and Space Complexity

Time Complexity: O(m × n)

Space Complexity: O(m × n)

Where m and n are the lengths of the two DNA sequences.

✅ Conclusion

The Longest Common Subsequence problem is successfully solved using Dynamic Programming. The algorithm finds the length of the longest sequence that occurs in both DNA samples while preserving the order of characters.
