🎯 Problem Statement

A logistics company in Bengaluru deploys autonomous drones to deliver medical supplies across multiple Indian cities.

Each drone must start from the headquarters (HQ). It must visit every city exactly once and finally return to HQ while minimizing the total travel cost such as fuel, distance, or time.

This problem is known as the Travelling Salesman Problem (TSP). Use Dynamic Programming to compute the minimum travel cost.

📋 Algorithm

  1. Represent HQ and all cities as vertices.
  2. Store the travel cost between every pair of cities.
  3. Start the drone from HQ.
  4. Use a bitmask to keep track of visited cities.
  5. Use Dynamic Programming to store the minimum cost for each state.
  6. Try visiting every unvisited city.
  7. After visiting all cities, add the cost of returning to HQ.
  8. Find and display the minimum possible travel cost.

💻 C Program

#include <stdio.h>

#define N 5
#define INF 999999

// Return the minimum of two values
int min(int a, int b)
{
    return (a < b) ? a : b;
}

// TSP using Dynamic Programming and Bitmasking
int tsp(int graph[N][N], int mask, int pos,
        int dp[1 << N][N])
{
    // All cities have been visited
    if (mask == (1 << N) - 1)
    {
        return graph[pos][0];
    }

    // Return already calculated result
    if (dp[mask][pos] != -1)
    {
        return dp[mask][pos];
    }

    int answer = INF;

    // Try visiting every unvisited city
    for (int city = 0; city < N; city++)
    {
        if ((mask & (1 << city)) == 0)
        {
            int newCost = graph[pos][city]
                        + tsp(graph,
                              mask | (1 << city),
                              city,
                              dp);

            answer = min(answer, newCost);
        }
    }

    dp[mask][pos] = answer;

    return answer;
}

int main()
{
    /*
       Cities:
       0 = HQ
       1 = A
       2 = B
       3 = C
       4 = D
    */

    int graph[N][N] =
    {
        {0, 10, 15, 20, 10},
        {10, 0, 35, 25, 17},
        {15, 35, 0, 30, 28},
        {20, 25, 30, 0, 16},
        {10, 17, 28, 16, 0}
    };

    // DP table
    int dp[1 << N][N];

    // Initialize DP table
    for (int i = 0; i < (1 << N); i++)
    {
        for (int j = 0; j < N; j++)
        {
            dp[i][j] = -1;
        }
    }

    // Start from HQ
    int start = 0;

    // Only HQ is visited initially
    int mask = 1 << start;

    // Calculate minimum travel cost
    int result = tsp(graph, mask, start, dp);

    printf("Minimum Travel Cost = %d\n", result);

    return 0;
}

🔍 Result

The Dynamic Programming based TSP algorithm calculates the minimum travel cost for the drone to start from HQ, visit every city exactly once, and return to HQ.

⏱️ Time and Space Complexity

Time Complexity: O(n² × 2ⁿ)

Space Complexity: O(n × 2ⁿ)

✅ Conclusion

The Travelling Salesman Problem is solved using Dynamic Programming and bitmasking. The algorithm efficiently finds the minimum travel cost while ensuring that every city is visited exactly once and the drone returns to the headquarters.
