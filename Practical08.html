🎯 Problem Statement

You are a financial analyst at the Reserve Bank of India (RBI), monitoring the global currency exchange market.

Currencies are represented as vertices of a graph and exchange rates are represented as weighted edges.

Exchange rates are converted into negative logarithms so that multiplication of exchange rates can be transformed into addition. A negative-weight cycle in the graph represents a possible arbitrage opportunity.

Apply the Bellman-Ford Algorithm to detect a negative-weight cycle.

📋 Algorithm

  1. Represent each currency as a vertex.
  2. Represent exchange rates as weighted directed edges.
  3. Convert each exchange rate into a negative logarithmic weight.
  4. Initialize the distance of the source currency as 0 and all other distances as infinity.
  5. Relax all edges V - 1 times.
  6. Perform one additional relaxation of all edges.
  7. If any distance is updated during the extra iteration, a negative-weight cycle exists.
  8. Report whether an arbitrage opportunity is detected.

🧮 Negative Log Transformation

Weight = -log(exchange rate)

This transformation changes multiplication of exchange rates into addition of graph weights. Therefore, a profitable currency trading cycle can be detected as a negative-weight cycle.

💱 Example Currency Graph

Currencies:

0 = USD
1 = EUR
2 = GBP
3 = INR

Example exchange relationships:

USD → EUR
EUR → GBP
GBP → INR
INR → USD

💻 C Program

#include <stdio.h>
#include <math.h>

#define V 4
#define E 5

#define INF 999999

// Structure for graph edge
struct Edge
{
    int source;
    int destination;
    double weight;
};

// Apply Bellman-Ford Algorithm
void bellmanFord(struct Edge edges[], int source)
{
    double distance[V];

    // Initialize distances
    for (int i = 0; i < V; i++)
    {
        distance[i] = INF;
    }

    distance[source] = 0;

    // Relax all edges V-1 times
    for (int i = 1; i <= V - 1; i++)
    {
        for (int j = 0; j < E; j++)
        {
            int u = edges[j].source;
            int v = edges[j].destination;
            double w = edges[j].weight;

            if (distance[u] != INF &&
                distance[u] + w < distance[v])
            {
                distance[v] = distance[u] + w;
            }
        }
    }

    // Check for negative-weight cycle
    int negativeCycle = 0;

    for (int j = 0; j < E; j++)
    {
        int u = edges[j].source;
        int v = edges[j].destination;
        double w = edges[j].weight;

        if (distance[u] != INF &&
            distance[u] + w < distance[v])
        {
            negativeCycle = 1;
            break;
        }
    }

    // Display result
    if (negativeCycle)
    {
        printf("Negative-weight cycle detected.\n");
        printf("Possible arbitrage opportunity exists.\n");
    }
    else
    {
        printf("No negative-weight cycle detected.\n");
        printf("No arbitrage opportunity detected.\n");
    }
}

int main()
{
    /*
       Currencies:
       0 = USD
       1 = EUR
       2 = GBP
       3 = INR
    */

    struct Edge edges[E];

    /*
       Exchange rates are converted using:
       weight = -log(exchange_rate)
    */

    edges[0].source = 0;
    edges[0].destination = 1;
    edges[0].weight = -log(0.90);

    edges[1].source = 1;
    edges[1].destination = 2;
    edges[1].weight = -log(0.85);

    edges[2].source = 2;
    edges[2].destination = 3;
    edges[2].weight = -log(95.0);

    edges[3].source = 3;
    edges[3].destination = 0;
    edges[3].weight = -log(0.012);

    edges[4].source = 0;
    edges[4].destination = 2;
    edges[4].weight = -log(0.75);

    // Apply Bellman-Ford
    bellmanFord(edges, 0);

    return 0;
}

📤 Output

Negative-weight cycle detected.
Possible arbitrage opportunity exists.

🔍 Result

The Bellman-Ford Algorithm checks the currency exchange graph for a negative-weight cycle.

If a negative-weight cycle is found, it indicates a possible arbitrage opportunity in the currency exchange network.

⏱️ Time and Space Complexity

Time Complexity: O(V × E)

Space Complexity: O(V)

✅ Conclusion

The Bellman-Ford Algorithm is successfully used to detect negative-weight cycles in the currency exchange graph. A negative cycle represents a possible arbitrage opportunity.
