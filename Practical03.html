📌 Problem Statement

You are an engineer aboard an ISRO interplanetary spacecraft travelling to Mars. The navigation computer needs to perform fast 4×4 matrix multiplications to continuously adjust the spacecraft's flight trajectory.

To reduce computational load, implement matrix multiplication using Strassen's Divide and Conquer Matrix Multiplication Algorithm. The 4×4 matrices are divided into 2×2 quadrants and Strassen's method is applied recursively.

⚙️ Algorithm — Strassen's Matrix Multiplication

  1. Take two 4×4 matrices A and B.
  2. Divide both matrices into four 2×2 sub-matrices.
  3. Calculate seven intermediate products using Strassen's method.
  4. Use matrix addition and subtraction to calculate the four result quadrants.
  5. Combine the four quadrants to form the final 4×4 matrix.
  6. Display the resulting matrix.

Seven Strassen Products

  • P1 = A11 × (B12 − B22)
  • P2 = (A11 + A12) × B22
  • P3 = (A21 + A22) × B11
  • P4 = A22 × (B21 − B11)
  • P5 = (A11 + A22) × (B11 + B22)
  • P6 = (A12 − A22) × (B21 + B22)
  • P7 = (A11 − A21) × (B11 + B12)
