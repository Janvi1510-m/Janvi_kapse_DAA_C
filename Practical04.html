📌 Problem Statement

A government is planning a nationwide high-speed fiber internet network connecting multiple cities. Each possible cable connection between cities has a different installation cost.

The government wants to connect all cities while minimizing the total construction cost. The task is to determine the minimum total cost required to connect all cities using Kruskal's Minimum Spanning Tree Algorithm.

⚙️ Algorithm — Kruskal's Algorithm

  1. Represent the cities as vertices and cable connections as weighted edges.
  2. Sort all edges in increasing order of their costs.
  3. Start with an empty Minimum Spanning Tree (MST).
  4. Select the edge with the smallest cost.
  5. Check whether adding the edge creates a cycle.
  6. If it does not create a cycle, add the edge to the MST.
  7. Continue until all cities are connected.
  8. Calculate and display the total minimum cost.

📥 Input Graph

The following cities and cable connections are used for demonstration:

Cities: A, B, C, D, E Edges: A - B : 4 A - C : 2 B - C : 1 B - D : 5 B - E : 7 C - D : 8 C - E : 10 D - E : 2

💻 C Code

#include <stdio.h> #define MAX 20 // Structure to store an edge struct Edge { int source; int destination; int weight; }; // Find the parent of a vertex int findParent(int parent[], int vertex) { if (parent[vertex] == vertex) { return vertex; } return findParent(parent, parent[vertex]); } // Join two sets void unionSets(int parent[], int rank[], int u, int v) { int rootU = findParent(parent, u); int rootV = findParent(parent, v); if (rootU != rootV) { if (rank[rootU] < rank[rootV]) { parent[rootU] = rootV; } else if (rank[rootU] > rank[rootV]) { parent[rootV] = rootU; } else { parent[rootV] = rootU; rank[rootU]++; } } } // Sort edges using Bubble Sort void sortEdges(struct Edge edges[], int edgeCount) { for (int i = 0; i < edgeCount - 1; i++) { for (int j = 0; j < edgeCount - i - 1; j++) { if (edges[j].weight > edges[j + 1].weight) { struct Edge temp = edges[j]; edges[j] = edges[j + 1]; edges[j + 1] = temp; } } } } int main() { int vertices = 5; int edgeCount = 8; struct Edge edges[MAX] = { {0, 1, 4}, {0, 2, 2}, {1, 2, 1}, {1, 3, 5}, {1, 4, 7}, {2, 3, 8}, {2, 4, 10}, {3, 4, 2} }; int parent[MAX]; int rank[MAX]; // Initialize each vertex as its own set for (int i = 0; i < vertices; i++) { parent[i] = i; rank[i] = 0; } // Sort all edges according to weight sortEdges(edges, edgeCount); int totalCost = 0; int edgesSelected = 0; printf("Edges selected in Minimum Spanning Tree:\\n"); // Apply Kruskal's Algorithm for (int i = 0; i < edgeCount; i++) { int source = edges[i].source; int destination = edges[i].destination; int rootSource = findParent(parent, source); int rootDestination = findParent(parent, destination); // Add edge only if it does not create a cycle if (rootSource != rootDestination) { printf("%c - %c : %d\\n", source + 'A', destination + 'A', edges[i].weight); totalCost += edges[i].weight; unionSets(parent, rank, rootSource, rootDestination); edgesSelected++; // MST contains V-1 edges if (edgesSelected == vertices - 1) { break; } } } printf("\\nMinimum Total Cost = %d\\n", totalCost); return 0; }

⏱️ Time and Space Complexity

Time Complexity: O(E log E)

The main time is used for sorting the edges according to their weights.

Space Complexity: O(V + E)

Here, V represents the number of vertices and E represents the number of edges.

📝 Conclusion

Kruskal's Minimum Spanning Tree Algorithm was successfully implemented to connect all cities with minimum total construction cost. The edges were sorted according to their weights and only those edges that did not form a cycle were selected.

The minimum total cost for the given network is 10.
