🎯 Problem Statement

You are developing a real-time emergency ambulance routing system for Mumbai, one of India’s busiest metropolitan cities.

Road intersections are represented as graph vertices. Roads are represented as weighted edges, where the weight indicates travel time affected by traffic density, road conditions, etc.

When an emergency occurs, the system must compute the shortest travel time from the hospital to all locations in the city so that ambulances can reach patients as quickly as possible. Implement Dijkstra’s Algorithm to solve this problem.

📋 Algorithm

  1. Represent the city as a weighted graph.
  2. Choose the hospital as the source vertex.
  3. Initialize the distance of the source as 0 and all other distances as infinity.
  4. Mark all vertices as unvisited.
  5. Select the unvisited vertex with the smallest distance.
  6. Update the distance of its adjacent vertices if a shorter path is found.
  7. Mark the selected vertex as visited.
  8. Repeat the process until all vertices are visited.
  9. Display the shortest travel time from the hospital to every location.

💻 C Program

#include <stdio.h>

#define V 6
#define INF 9999

// Find the vertex with minimum distance
int minDistance(int dist[], int visited[])
{
    int min = INF;
    int minIndex = -1;

    for (int i = 0; i < V; i++)
    {
        if (!visited[i] && dist[i] < min)
        {
            min = dist[i];
            minIndex = i;
        }
    }

    return minIndex;
}

// Print shortest distances
void printDistances(int dist[])
{
    char locations[V] = {'H', 'A', 'B', 'C', 'D', 'E'};

    printf("Shortest travel time from Hospital (H):\n\n");

    for (int i = 0; i < V; i++)
    {
        printf("Hospital to %c = %d minutes\n",
               locations[i], dist[i]);
    }
}

// Dijkstra's Algorithm
void dijkstra(int graph[V][V], int source)
{
    int dist[V];
    int visited[V];

    // Initialize distances and visited array
    for (int i = 0; i < V; i++)
    {
        dist[i] = INF;
        visited[i] = 0;
    }

    // Distance from source to itself is zero
    dist[source] = 0;

    // Find shortest paths
    for (int count = 0; count < V - 1; count++)
    {
        int u = minDistance(dist, visited);

        if (u == -1)
        {
            break;
        }

        visited[u] = 1;

        // Update adjacent vertices
        for (int v = 0; v < V; v++)
        {
            if (!visited[v] &&
                graph[u][v] != 0 &&
                dist[u] != INF &&
                dist[u] + graph[u][v] < dist[v])
            {
                dist[v] = dist[u] + graph[u][v];
            }
        }
    }

    printDistances(dist);
}

int main()
{
    /*
       Vertices:
       0 = Hospital (H)
       1 = A
       2 = B
       3 = C
       4 = D
       5 = E
    */

    int graph[V][V] =
    {
        {0, 4, 2, 0, 0, 0},
        {4, 0, 1, 5, 0, 0},
        {2, 1, 0, 8, 10, 0},
        {0, 5, 8, 0, 2, 6},
        {0, 0, 10, 2, 0, 3},
        {0, 0, 0, 6, 3, 0}
    };

    // Hospital is the source vertex
    int source = 0;

    // Apply Dijkstra's Algorithm
    dijkstra(graph, source);

    return 0;
}

🔍 Result

The Dijkstra algorithm successfully finds the shortest travel time from the hospital to all other locations in the city.

For example, the shortest route from Hospital to A is: H → B → A, with a total travel time of 3 minutes.

✅ Conclusion

Dijkstra’s Algorithm efficiently determines the shortest travel time from the hospital to all locations in the weighted road network. It can help an emergency ambulance routing system identify faster routes for reaching patients.
